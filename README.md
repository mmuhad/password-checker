# Password Strength Checker

a simple python script that rates how strong a password is, from "very weak" to "very strong".

## what it checks
- length (12+ characters)
- lowercase letters
- uppercase letters
- numbers
- special characters

## how to run
1. make sure Python 3 is installed.
2. download `pwd_checker.py`.
3. run it in your terminal:

   pwd_checker.py

4. yype a password when asked and see its rating.

## what I learned
- using `input()` and functions in Python
- pattern matching with the `re` (regular expressions) module
- why password length and variety matter for security
